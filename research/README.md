# research/ — 사용자가 수집한 종목 자료 인입함

증권사 리포트, IR 자료, 뉴스 스크랩 등 **사용자가 직접 수집한 자료**를 넣는 곳.
여기 들어온 자료는 다음 작업 때 읽고 모델·정성 레이어에 반영한다.

```
research/<종목 디렉터리명>/YYYYMMDD_종목_출처.pdf
```

- 종목 디렉터리명은 `companies/`와 같게 (samsung-em · ktg · tlb · lgd · sec)
- 파일명 앞의 날짜는 자료 발행일. 출처는 증권사·매체 이름
- PDF 외 형식(스크린샷·텍스트·엑셀)도 같은 규칙으로

## 반영 규약

자료를 읽고 반영할 때의 원칙 — `.claude/skills/ic-model/SKILL.md` §5c 참조.

1. **공시로 확정 가능한 사실**(수주 공시, 분기 실적, 증설 발표)은 확정값으로
   반영한다 — 리포트는 발견의 경로일 뿐, 근거는 공시 원문이다.
2. **애널리스트 추정치·목표주가**는 [외생] 참고 정보 — 컨센서스 카드·심사
   쟁점의 대조 상대로 쓰고, 본 모델 가정에 베끼지 않는다.
3. **회사 가이던스**는 [외생]으로 명시해 반영할 수 있다.
4. 가정을 바꾸면 반드시 `MEMO.revision`에 무엇을 왜 바꿨는지 기록하고,
   `MARKET.history`에 직전 (주가, 적정가) 쌍을 남긴다.
5. 반영이 끝난 자료도 지우지 않는다 — 판단의 근거 이력이다.
