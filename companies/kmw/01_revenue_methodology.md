# 케이엠더블유 — 매출 설계

## 분해: 품목 4개 (연결 기준 공시)

```
총매출 = RF SYSTEM + RF ANTENNA + RF FILTER류·기타 + LED
```

- 근거: 사업보고서 II-4 '매출실적' 표가 **연결 기준** 품목 분해를 5개년 공시
  (부문 주석의 RF/LED는 내부거래 제거 전 총계 — 제거액이 매출의 41%라 쓸 수 없음)
- FILTER류·기타는 합계 정합을 위해 IS 매출에서 역산 (공시 표와 ≤0.007억 차이)
- 물량·단가 공시 없음 → Q×P 분해하지 않는다 (규약)

## 바인딩: 수요 (통신사 CAPEX 사이클)

- 전방: 삼성전자(2025 매출의 47.8%) → 미국·일본·국내 통신사. ZTE 16.2%(중국)
- 회사가 통제하는 변수가 아님 — 주파수 경매·통신사 투자 사이클에 종속
- 생산능력 제약 없음 (2019년 매출 6,829억 처리 실적, 현재 975억 — 가동률 바닥)

## 확정 사실 (2026-09-15 기준)

- 5년 연속 영업적자: −279 → −450 → −629 → −455 → −238억
- 2026 H1 확정: 매출 458.1억 (**YoY −10.9% 역성장**) · 영업이익 −120.0억
- 수주잔고 비공시. 단일판매공급계약 공시 최근 2년 1건(2024.5 자율공시)뿐
- 버라이즌 AWS-3 65MHz 확보(2026.6)·미국 어퍼C밴드 경매 2027.4 예정은 외생 사실.
  단, "삼성전자 벤더 선정"과 "KMW 채택"은 모두 미확정 추정

## Base 경로 — 경매는 열리나 수혜는 완만·후행

역사적 반례가 기준: 2021년 C밴드 경매 + 삼성 버라이즌 $6.6B 수주에도 KMW
매출은 2020 3,385 → 2021 2,052 → 2022 1,795억으로 **줄었다**. "경매 = KMW
폭발"은 2019년(화웨이·노키아향 5G 초기 물량) 한 번의 경험이다.
