## 배경 (해결 전 기록)

DART 접근이 차단됐을 때 검색 스니펫만으로 채우려 했으나 결과가 서로 충돌했다
(FY2021 매출이 한 곳은 71,997억, 다른 곳은 96,750억). 원문 확인 결과 **96,750억이
맞았고** 낮은 쪽 출처는 2021·2022의 매출·영업이익 네 항목이 모두 틀렸다.
근사치를 모델에 넣었다면 5개년 추세 전체가 왜곡됐을 것이다.

## 필요한 항목

### 1. 연결 손익계산서 (필수) — ✅ 확보

최근 **5개 사업연도**. 사업보고서 → 재무제표 → 연결 포괄손익계산서.

| 항목 | 비고 |
|---|---|
| 매출액 | 연결 기준 |
| 매출원가 | 비용 레이어(Phase 2)에서 사용 |
| 매출총이익 | |
| 판매비와관리비 | |
| 영업이익 | |

### 2. 부문별 정보 (필수 — 이게 핵심) — ✅ 확보

사업보고서 → 주석 → **영업부문 정보**. 또는 IR 실적발표의 부문별 매출.

최근 5개 사업연도, **연간** 기준:

| 부문 | 매출액 | 영업이익 |
|---|---|---|
| 컴포넌트 | | |
| 광학통신솔루션 | | |
| 패키지솔루션 | | |
| 부문 간 내부거래 제거 | | 별도 공시되면 |
| **합계** | | 총매출과 일치해야 함 |

> **주의**: IR 보도자료의 부문별 수치는 대개 **분기** 기준이다.
> 연간과 분기를 섞으면 안 된다. 검색 결과에서 실제로 이 혼동이 있었다.

### 3. 유형자산·CAPEX (Phase 2용) — ⬜ 미확보

| 항목 | 비고 |
|---|---|
| 유형자산 기초/기말 장부가 | 롤포워드 검증용 |
| 유형자산 취득(CAPEX) | 증설 규모 |
| 감가상각비 | 원가의 큰 축 |

### 4. 정성 지표 (있으면 좋음) — ⬜ 미확보

IR 자료·컨퍼런스콜에서 회사가 밝힌 비중. 없으면 추정으로 대체한다.

- 컴포넌트 내 **전장·서버향 매출 비중** (%)
- 패키지솔루션 내 **FC-BGA 비중** (%)
- 패키지 라인 증설 계획 — 양산 시점, 투자 규모

## historicals.json 스키마

```json
{
  "_source": "삼성전기 사업보고서 (2025.12) 연결 포괄손익계산서 · 영업부문 정보",
  "_unit": "억원",
  "_years": ["2021", "2022", "2023", "2024", "2025"],

  "root":            [ , , , , ],
  "component_total": [ , , , , ],
  "optics_total":    [ , , , , ],
  "package_total":   [ , , , , ]
}
```

- 키는 `data.js`의 노드 id와 같아야 한다.
- 값 배열의 길이는 실적 연도 수(`HIST_N`)와 같다.
- `_`로 시작하는 키는 검증에서 무시한다 — 출처·단위 메모용.

게이트 G1이 이 값과 모델 산출값을 대사하고, 하나라도 어긋나면 실패한다.
